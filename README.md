# 오늘의 자리 — 개인정보처리방침

지하철 하차 알림·좌석 공유 앱 **「오늘의 자리」** 의 개인정보처리방침을 공개하기 위한
저장소다. App Store / Google Play 제출 시 요구되는 공개 URL 로 쓴다.

공개 주소: https://lxxjs.github.io/oneuljari-privacy/

## 이 저장소에 있는 것

`index.html` 하나뿐이다. 의존성도 빌드도 없다.

**원본은 앱 저장소의 `docs/PRIVACY_POLICY.md` 다.** 내용을 고칠 때는 원본을 먼저
고치고 여기로 옮긴다. 앱 동작과 방침이 어긋나지 않게 하려면 근거가 코드 옆에
있어야 한다.

## 데이터 보관 위치

대한민국 (AWS 서울 리전 `ap-northeast-2`). 5항의 근거값이며 Supabase 프로젝트의
리전과 반드시 일치해야 한다 — 「개인정보 보호법」 제28조의8 의무 고지다.

## 남은 작업

10항 **개인정보 보호책임자**의 성명·연락처가 아직 비어 있다(`작성 예정` 표시).
**이 값을 채우기 전에는 App Store 에 이 URL 을 제출하면 안 된다.**
